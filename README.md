# SSM Connect releases

Downloads for **SSM Connect**, a Mac app for AWS Session Manager: shell sessions, port forwarding,
SSO login and more, organised like an SSH config editor.

**Download:** the `.dmg` from the [latest release](https://github.com/Latrixz/ssm-connect-releases/releases/latest).
Open it and drag SSM Connect to Applications. It's signed and notarized by Quantum Apes, so it opens
without warnings, and it updates itself from here.

**You'll also need** the AWS tools: `brew install awscli session-manager-plugin`.

Works on macOS 14 or later, Apple Silicon and Intel.
